NEON PURSUIT

Un simulador arcade de conducción de superbikes en una megaciudad nocturna. Atraviesa autopistas, túneles y puentes mientras la policía cierra el cerco. Tu única salida es la velocidad.

Proyecto original construido con geometría 3D procedural, Babylon.js, TypeScript, Web Audio API y Vite. Todos los edificios, vehículos, motocicletas, letreros y sonidos se generan en tiempo de ejecución: no depende de recursos externos que puedan desaparecer.

TECNOLOGÍA

  • Babylon.js 9 · WebGL2 / WebGPU
  • TypeScript estricto + Vite
  • Controlador físico propio a delta time fijo
  • Audio sintetizado con Web Audio API
  • PWA instalable con Service Worker
  • Geometría instanciada y fusionada

CONTENIDO ORIGINAL

  • Ciudad procedural de ~6 km
  • Dos superbikes con estadísticas reales
  • Tráfico civil con IA de carril
  • Persecución policial de 5 niveles
  • Helicóptero de vigilancia
  • Música electrónica generativa
Nota técnica: esta primera versión usa un controlador cinemático estable en lugar de una simulación rígida completa. La arquitectura deja preparada la sustitución de modelos procedurales por GLB y la integración de físicas avanzadas (Havok / Physics V2) sin reescribir el juego.
